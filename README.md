# Курсовой проект. Распознавание рукописных цифр на NumPy

Напишите нейросеть, которая получает изображение рукописной цифры и определяет её класс от 0 до 9. Начните с одного нейрона из лекции, соберите из таких вычислений полносвязный слой и соедините два слоя в сеть прямого распространения (feed-forward). Затем обучите сеть и разберите её ошибки на MNIST.

```text
Изображение 28 × 28 → 784 значения → Dense(H) → ReLU → Dense(10) → 10 логитов
```

NumPy — единственная внешняя зависимость. Вы сами реализуете прямой проход, функцию потерь, обратное распространение и обновление параметров. Обучение рассчитано на CPU. Код загрузки MNIST, запуска экспериментов и сохранения метрик уже есть в репозитории.

## Как начать

Понадобится Python 3.10 или новее. Откройте терминал в корне своей копии репозитория.

**Windows PowerShell**

```powershell

.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

**Linux и macOS**

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

Если PowerShell ограничивает запуск `Activate.ps1`, подставьте `.\.venv\Scripts\python.exe` вместо `python` в командах установки и запуска.

Проверьте запуск первого этапа. До заполнения заготовок он выдаёт `NotImplementedError` с именем функции. Для этих тестов MNIST скачивать не нужно.

```bash
python -m unittest tests.test_neuron -v
```

Скачайте MNIST и посмотрите первую цифру в терминале. Файлы сохраняются в `data/mnist/`. Если скачивание из терминала недоступно, можно положить в этот каталог четыре `.gz`-файла с [зеркала MNIST](https://github.com/cvdfoundation/mnist#download).

```bash

```

## Этап 1. Один нейрон

Заполните `relu` и `Neuron.forward` в [`layers.py`](mnist_numpy/layers.py). Для входа $x$ сначала вычислите взвешенную сумму $z = \sum_i w_i x_i + b$, затем выход $a = \max(0, z)$.

Возьмите пример с лекции. При $w = 1{,}2$ и $b = -0{,}5$ вход $x=-1$ даёт $z=-1{,}7$ и $a=0$. При $x=1$ получаем $z=0{,}7$ и $a=0{,}7$. В отчёте приведите свой ручной расчёт для нейрона с несколькими входами.

```bash
python -m unittest tests.test_neuron -v
```

## Этап 2. Полносвязный слой

Реализуйте `Dense` и `ReLU` в [`layers.py`](mnist_numpy/layers.py). В `Dense` каждый столбец матрицы весов соответствует одному нейрону, а каждый элемент вектора смещений — его $b$. Сначала проверьте на маленьком примере, что отдельные нейроны и `Dense → ReLU` дают одинаковый результат. Батч в `Dense` обрабатывайте матричными операциями NumPy.

| Обозначение | Форма | Смысл |
| --- | --- | --- |
| `x` | `(B, D)` | Батч из `B` объектов, `D` входов на нейрон |
| `weights` | `(D, H)` | Веса `H` нейронов |
| `bias` | `(H,)` | Смещения `H` нейронов |
| `z` | `(B, H)` | Взвешенные суммы до активации |

Инициализируйте веса случайно через переданный `rng`. Для старта подойдёт нормальное распределение со стандартным отклонением $\sqrt{2/D}$ и нулевые смещения. Используйте `float32` для параметров, чтобы при обучении массивы занимали меньше памяти.

В `backward` вы получаете градиент потерь по выходу слоя. Вычислите градиенты по входу, весам и смещениям. Сохраните то, что понадобится из прямого прохода. Подумайте, сколько объектов батча влияет на один общий `bias[j]` и какие оси надо суммировать. Для ReLU примите производную в нуле равной нулю.

Тесты сравнивают градиенты с центральной разностью $[f(t+\varepsilon)-f(t-\varepsilon)]/(2\varepsilon)$ на маленьких массивах. Здесь $t$ — один проверяемый элемент, а $f$ — скалярная функция от результата прямого прохода.

```bash
python -m unittest tests.test_layers -v
```

## Этап 3. Логиты и потери

Заполните `softmax_cross_entropy` в [`loss.py`](mnist_numpy/loss.py). Вход — логиты формы `(B, C)` и метки формы `(B,)`, где `C` — число классов. Softmax преобразует каждую строку логитов в вероятности. Потеря одного объекта — минус логарифм вероятности правильного класса. Верните среднюю потерю и её градиент по логитам.

Проверьте устойчивость на строке `[1000, -1000]`. При правильном классе `1` потеря должна быть близка к `2000`. Softmax сохраняется при вычитании максимума из всей строки. Используйте это свойство и вычислите логарифм вероятности через логарифм суммы экспонент. Для вывода класса достаточно взять индекс максимального логита.

```bash
python -m unittest tests.test_loss -v
```

## Этап 4. Сеть и обучение

1. Соберите `Dense → ReLU → Dense` в [`model.py`](mnist_numpy/model.py). Последний слой выдаёт логиты. Проведите градиент в обратном порядке. Параметры обоих слоёв обновляйте после вычисления всех градиентов.
2. Заполните `train_epoch` в [`training.py`](mnist_numpy/training.py). Перемешайте индексы через переданный `rng` и берите изображения и метки по одним и тем же индексам. Для каждого мини-батча выполните прямой проход, расчёт потерь, обратный проход и шаг градиентного спуска. Учтите последний батч, даже если он короче остальных.
3. Усредните потери эпохи по объектам. Градиент из `softmax_cross_entropy` уже относится к средней потере батча, поэтому деление на размер батча учитывается в нём один раз.

```bash
python -m unittest tests.test_model tests.test_training -v
python -m unittest discover -v
python train.py --epochs 2 --limit-train 1024 --run-dir runs/quick
```

## Этап 5. Эксперимент на MNIST

Загрузчик разворачивает изображение в 784 признака и переводит яркости из диапазона `0–255` в `[0, 1]`. Из исходной обучающей части он выделяет **55 000** изображений для обучения и **5 000** для валидации. Разбиение фиксировано. Исходные **10 000** тестовых изображений используются для финальной оценки. [Описание датасета MNIST](https://github.com/cvdfoundation/mnist)

Сравните два значения ширины скрытого слоя при одинаковых числе эпох, размере батча, скорости обучения и seed. Например, `32` и `64`. Выберите конфигурацию по валидационной `accuracy`, то есть доле верно распознанных цифр. Затем повторите выбранный запуск с `--test` и теми же параметрами. Указывайте новый `--run-dir` для каждого запуска.

```bash
python train.py --hidden-size 32 --run-dir runs/width32
python train.py --hidden-size 64 --run-dir runs/width64
# Пример финальной команды, если по валидации выбран слой из 64 нейронов
python train.py --hidden-size 64 --test --run-dir runs/final
```

По умолчанию `train.py` использует 10 эпох, размер батча 128, скорость обучения 0.1 и seed 42. Полный список аргументов показывает `python train.py --help`. **95% accuracy на тесте — ориентир для базовой сети.** Обоснуйте полученный результат по кривым или таблице обучения и по ошибкам модели.

| Файл запуска | Что в нём |
| --- | --- |
| `history.csv` | Потери на обучении и валидации, валидационная accuracy по эпохам |
| `metrics.json` | Параметры запуска и итоговые метрики |
| `confusion.csv` | Матрица ошибок финального запуска. Строки — верный класс, столбцы — предсказание |
| `mistakes.csv` | Индексы ошибочно распознанных тестовых цифр, верные и предсказанные классы |

Чтобы посмотреть ошибку из `mistakes.csv`, подставьте её `test_index` вместо `8` в команде `python -m mnist_numpy.data --split test --index 8`.
